## 2. F-17 播放地址签名与 HLS 全链路校验

### 2.1 签名算法

```
token = HMAC-SHA256(PLAY_TOKEN_SECRET, path + "|" + expire)   // 32 位小写 hex
url   = path + "?expire=" + expire + "&token=" + token
```

- `path`：不带 query 的站点相对路径，如 `/hls/12/master.m3u8`
- `expire`：Unix 秒级时间戳
- master.m3u8 有效期：`PLAY_TOKEN_EXPIRE_SECONDS`（默认 7200 秒 = 2 小时，文档 7.3.4）
- m3u8 内部的子列表/切片有效期：`PLAY_SEGMENT_EXPIRE_SECONDS`（默认 43200 秒 = 12 小时），
  避免 3 小时长视频播放到后半段时切片签名过期

### 2.2 全链路校验（关键设计）

HLS 播放器只会携带 master 的 query 参数，后续子列表/切片请求默认不带签名，因此：

1. `GET /hls/{episodeId}/master.m3u8`：校验签名 → 读取文件 → **把子列表行改写为带签名地址**
   （`/hls/{id}/720p/index.m3u8?expire=&token=`）
2. `GET /hls/{episodeId}/{720p|480p}/index.m3u8`：校验签名 → **把切片行改写为带签名地址**
3. `GET /hls/{episodeId}/{720p|480p}/seg_XXXXX.ts`：校验签名 → 返回 TS 二进制（支持 Range）

实现：`PlayTokenService`（签名/校验）+ `HlsStreamController`（校验、m3u8 改写、TS 分发）。
`/hls/**` 不再由静态资源处理器暴露，避免绕过签名直取文件。

### 2.3 部署调整

- 生产 Nginx：`/hls/` 由静态 `alias` 改为 `proxy_pass http://app:8080`（见 `deploy/nginx/conf.d/vidkeep.conf`）
- 取舍：HLS 流量经过 Java 层，牺牲了 Nginx 静态分发的性能；当前规模（50 并发 / 75 Mbps）可接受。
  若后续要 CDN/Nginx 静态分发，需改用 Nginx `secure_link` 并同步实现切片级签名与播放列表改写。
- 错误码：签名缺失/过期/篡改 → HTTP 403 + `code=2005`

## 3. F-18 站点访问口令

### 3.1 行为

- 配置：`.env` 的 `SITE_ACCESS_PASSWORD`，**留空 = 不启用**（默认关闭）
- 前端入口：
  - `GET /api/public/site/status` → `{enabled}`（免口令）
  - `POST /api/public/site/verify` `{password}` → 校验通过后下发 HttpOnly cookie `vidkeep_site_token`
    （HMAC 令牌，默认 30 天，SameSite=Lax）
  - 口令错误 → `code=2006`
- 拦截范围（启用时）：`/api/public/**`（除 status/verify）、`/hls/**`、`/covers/**`
  - 未通过口令访问 API：HTTP 200 + `code=2004`（前端弹口令框）
  - 未通过口令访问媒体：HTTP 403
- **管理员 JWT 豁免**：已带有效 Bearer Token 的请求直接放行（后台不受站点口令影响）

### 3.2 前端

`components/SiteGate.vue` 全屏口令遮罩，挂在 `PortalLayout`；`request.ts` 收到 `2004` 时派发
`window` 事件触发弹窗；通过后整页刷新。

## 4. F-19 管理员操作日志

文档 01 未定义审计表，本阶段新增表 `admin_operation_log`（见 `deploy/sql/init.sql`，`CREATE TABLE IF NOT EXISTS` 幂等）。

| 列 | 说明 |
|---|---|
| user_id / username | 操作管理员 |
| module / action | 模块（视频/分类/上传/转码/日志/其他）与动作（新增视频/删除视频/…） |
| method / path / detail | HTTP 方法、路径、query 摘要（失败时附错误信息） |
| ip / duration_ms / created_at | 来源 IP、耗时、时间 |

实现：

- `OperationLogAspect`：Spring AOP 拦截 `com.vidkeep.module..controller` 的请求，
  仅记录 `/api/admin/**` 下的 POST/PUT/PATCH/DELETE（分片上传 `chunk` 与秒传 `check` 排除，避免刷屏）
- 记录失败不影响主流程（异常吞掉并 warn）
- 查询：`GET /api/admin/operation-logs?page&size&username&module`（ADMIN）
- 后台页面：`/admin/logs`（菜单「操作日志」）

## 5. F-15 播放统计

- **播放次数**：`video.view_count` 在「成功获取播放地址」时 +1
  （`PlayService` 内 `view_count = view_count + 1`；同一设备刷新会重复计数，P1 阶段接受该粗口径）
- **观看时长**：`video_episode`/`play_history` 模型下不新增统计表，
  口径为 `SUM(play_history.duration)`（每台设备每集保留最后一次观看时长）
- **接口**：`GET /api/admin/stats` → `{videoCount, categoryCount, episodeCount, transcodingCount,
  totalViewCount, totalWatchSeconds}`
- **前端**：仪表盘 5 张统计卡（视频总数/分类数/转码中/播放次数/累计观看时长）

## 6. 错误码扩展（P1）

| 码 | 含义 | 使用场景 |
|---|---|---|
| 2004 | 需要访问口令 | 站点口令未通过（API） |
| 2005 | 播放地址无效或已过期 | 签名缺失/过期/篡改（HTTP 403） |
| 2006 | 访问口令错误 | 口令校验失败 |

## 7. 配置项与环境变量

| 环境变量 | 说明 | 默认 |
|---|---|---|
| `PLAY_TOKEN_SECRET` | 播放签名密钥（≥32 字节） | 必填（未配置时回退 JWT_SECRET） |
| `PLAY_TOKEN_EXPIRE_SECONDS` | master 签名有效期 | 7200 |
| `PLAY_SEGMENT_EXPIRE_SECONDS` | 子列表/切片签名有效期 | 43200 |
| `SITE_ACCESS_PASSWORD` | 站点访问口令，留空=关闭 | 空 |
| `SITE_TOKEN_SECRET` | 口令 cookie 签名密钥（≥32 字节） | 回退 JWT_SECRET |
| `SITE_TOKEN_EXPIRE_SECONDS` | 口令 cookie 有效期 | 2592000（30 天） |
| `SITE_COOKIE_NAME` | 口令 cookie 名 | vidkeep_site_token |

## 8. 验证方式

```bash
# 主链路（8081 备用实例，含签名/改写/播放量/统计/审计）
python scripts/dev/e2e-video-flow.py --base http://localhost:8081 --expect-mode TRANSCODE

# 站点口令专项（8082 备用实例，开启 SITE_ACCESS_PASSWORD=dev-gate）

```

## 9. 已知限制

1. 播放签名与站点口令共用服务端密钥；更换密钥会使所有已签发播放地址/口令 cookie 立即失效（符合预期）。
2. m3u8 每次请求实时改写（含逐切片签名），大并发下 CPU 开销高于静态分发；当前规模可接受。
3. 播放次数为粗口径（刷新/重复播放会累计）；观看时长为「每设备每集最后一次时长」的汇总，不是精确播放时长。
4. 审计日志目前只增不删，后续可加定期归档/清理任务（M4）。
5. 站点口令为单一共享口令，不支持多口令/访客账号（文档 F-18 仅要求全站口令）。
