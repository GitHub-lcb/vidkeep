# 前端设计规范 —— 主界面（前台）与管理后台

| 项 | 内容 |
|---|---|
| 文档版本 | v1.0 |
| 编写日期 | 2026-11-17 |
| 状态 | 已落地（M0–M3 + P1 全部页面） |
| 适用范围 | `video-web/` 全部页面与组件 |
| 事实来源 | `src/styles/_variables.scss`、`_base.scss`、各页面 SFC 的 scoped 样式 |

> 本规范描述**当前代码里真实生效**的设计系统。新增页面前先读本文，保证与既有页面视觉一致。
> 设计令牌只有一处真源：`src/styles/_variables.scss`；本文是它的使用说明。

---

## 1. 设计原则

1. **克制、不做模板感**：单一蓝色强调色 `#5b8def` + 深色 ink 中性色阶，不用彩虹色、不用大面积渐变堆叠。
2. **双端同源、侧重不同**：前台重"沉浸浏览"（深色），后台重"信息密度与效率"（深色侧栏 + 浅色内容区）；两端共享同一套变量与字体。
3. **内容优先**：封面/标题/状态是视觉主体；装饰只做极淡网格、光晕、描边。
4. **状态必须可见**：加载（骨架/loading）、空态、错误、转码状态、上下架状态都有明确视觉。
5. **可维护**：颜色/断点只用变量；页面私有样式写 scoped；Element Plus 只做主题变量覆盖，不 fork 组件。

## 2. 双端结构对照

| 维度 | 前台（Portal） | 管理后台（Admin） |
|---|---|---|
| 路由前缀 | `/`、`/videos/:id`、`/play/:videoId/:episodeId` | `/admin/**` |
| 底色 | 深色 ink（`#080c13` 起） | 浅色 `#f5f6f8` 内容区 + 深色侧栏 `#0d131e` |
| 布局外壳 | `layouts/PortalLayout.vue` | `layouts/AdminLayout.vue` |
| 导航 | 顶部 sticky 顶栏（64px，毛玻璃） | 左侧 220px 侧栏 + 60px 顶栏；≤900px 折叠为顶栏横向菜单 |
| 内容容器 | 1120px 居中，左右 24px（移动端 16px） | 全宽流式，内容区使用 `.vk-page` 内边距 |
| 字体主色 | `$vk-text #e8edf5` | `$vk-light-text #1f2733` |
| 信息密度 | 低（大留白、卡片网格） | 高（筛选卡 + 表格 + 分页） |
| 特殊页面 | 站点口令全屏遮罩（`SiteGate`） | 登录页 `Login`（深色居中卡片） |

## 3. 设计令牌

### 3.1 色彩

**深色面（前台 / 后台侧栏 / 登录 / 口令弹窗）**

| 变量 | 值 | 用途 |
|---|---|---|
| `$vk-ink-900` | `#080c13` | 前台页面最底色 |
| `$vk-ink-800` | `#0d131e` | 后台侧栏、卡片渐变深端 |
| `$vk-ink-700` | `#111826` | 封面占位、深色块 |
| `$vk-ink-600` | `#151d2b` | 深色分层 |
| `$vk-line` | `rgba(255,255,255,.08)` | 深色面分隔线/描边基准 |
| `$vk-text` | `#e8edf5` | 深色面主文字 |
| `$vk-text-muted` | `#8b97a8` | 深色面次要文字 |
| `$vk-accent` | `#5b8def` | 品牌强调色（唯一强调色） |

**浅色面（后台内容区）**

| 变量 | 值 | 用途 |
|---|---|---|
| `$vk-light-bg` | `#f5f6f8` | 后台页面底色 |
| `$vk-light-surface` | `#ffffff` | 卡片/表格/顶栏表面 |
| `$vk-light-border` | `#e8ebf0` | 浅色描边/分隔线 |
| `$vk-light-text` | `#1f2733` | 浅色面主文字 |
| `$vk-light-text-muted` | `#7b8698` | 浅色面次要文字 |

**Element Plus 主题映射**（`_base.scss` 的 `:root`）：主色 `#5b8def`，`light-3/5/7/8/9 = #7ba4f5 / #9dbcfa / #c2d5fc / #d6e3fd / #eef3ff`，`dark-2 = #4a76cf`。

**常用衍生值（不新增变量，按需使用）**

- 深色面半透明填充：`rgba(255,255,255,.025/.04/.05/.06)`；描边 `rgba(255,255,255,.06/.07/.08/.10/.12)`
- 强调色半透明：`rgba(91,141,239,.10/.16/.18/.32/.45/.62)`
- 浅色面辅助：表头/拖拽区 `#fafbfc`、浅蓝 hover `#f5f8ff`、虚线 `#d4dae3`、表头文字 `#5b6678`、错误文字 `#f08181`
- 主按钮渐变：`linear-gradient(180deg, #5f8ff2, #4a76d6)`；hover `#6d9af5 → #4f7cdd`

> 规则：新增页面**优先复用变量与已出现的衍生值**；确实需要新颜色时先加变量，禁止在页面里随手写新 hex。

### 3.2 字体与字号阶梯

字体栈：`$vk-font-sans`（system-ui / PingFang SC / Microsoft YaHei / Roboto …），全局 `body 14px / line-height 1.6`，抗锯齿开启。

| 尺寸 | 典型用途 |
|---|---|
| 11px | eyebrow、时长角标、分类角标、侧栏副标题 |
| 12px | 辅助说明、页脚、表单错误提示、统计 hint |
| 12.5px | 前台筛选 chip、结果统计文字 |
| 13px | 表单 label、表格表头、导航、按钮文字、后台顶栏 |
| 14px | 正文、卡片标题、视频卡片标题、上传文件名 |
| 15px | 页面区块标题、后台 header 标题、上传面板标题 |
| 16–17px | 品牌名（前台 17 / 口令弹窗 16） |
| 20px | 页面主标题（`.vk-page__title`、登录标题） |
| 28px | 后台统计数字 |
| `clamp(38px, 6vw, 64px)` | 前台首页 Hero 标题 |

字重：400 常规 / 500 eyebrow / 600 标题与数值 / 650 品牌字 / 700 Hero。
字距：品牌名与标语 `0.04em`，eyebrow `0.32em`，Hero 标题 `-0.03em`。数字类（时长、统计）用 `font-variant-numeric: tabular-nums`。

### 3.3 间距与栅格

基准 8px 栅格，常用值：4 / 6 / 8 / 10 / 12 / 13 / 16 / 18 / 20 / 22 / 24 / 28 / 32 / 34 / 36 / 40 / 64 / 72。

| 场景 | 值 |
|---|---|
| 后台页面内边距 `.vk-page` | `24px 28px 40px`（≤900px：`16px`） |
| 后台卡片内边距 | `20px`（筛选卡 `18px 20px 2px`；表格卡 `4px 20px 16px`） |
| 前台容器 | 最大 1120px，左右 24（移动端 16） |
| 前台 Hero | 上 64 / 下 30（平板 48/24，手机 36/20） |
| 卡片网格间距 | 前台 20（平板 16 / 手机 13）；后台 `.vk-grid` 16 |
| 区块间距 | 16 / 18 / 20 / 34 |

### 3.4 圆角

| 值 | 用途 |
|---|---|
| 5px | 时长角标 |
| 7–8px | 品牌 logo 方块、输入框、按钮、侧栏菜单项 |
| 9px | 深色面输入框 |
| 10px | 提示条、上传文件条 |
| 12px | **卡片/表格/筛选卡默认圆角** |
| 14–16px | 登录卡/口令卡（移动端 14） |
| 999px | chip、分类角标（胶囊） |

### 3.5 阴影与描边

- 浅色面：**只用 1px 边框**，不加阴影（`$vk-light-border`），保持后台轻量。
- 深色面卡片 hover：`0 14px 34px rgba(0,0,0,.38)` + 边框变强调色 45% 透明。
- 登录/口令卡：`0 24px 80px rgba(0,0,0,.5)` + `inset 0 1px 0 rgba(255,255,255,.04)`。
- 品牌小方块/强调按钮：`0 6px 18px rgba(91,141,239,.32)`、`0 10px 24px rgba(74,118,214,.32)`。

### 3.6 动效

- 过渡时长 `0.18s–0.22s ease`；封面缩放 `0.35s ease`。
- 交互：卡片 hover 上浮 `translateY(-3px)`；封面 `scale(1.045)`；播放按钮淡入。
- 骨架屏：1.4s 渐变扫光动画。
- 必须尊重 `prefers-reduced-motion: reduce`（已有卡片实现示例，新动画照做）。

### 3.7 断点与响应式

| 断点 | 变量/mixin | 主要变化 |
|---|---|---|
| ≤900px | `$vk-breakpoint-tablet` / `vk-tablet` | 后台侧栏收起为顶栏横向菜单；前台工具栏纵向堆叠；网格降列 |
| ≤640px | `$vk-breakpoint-mobile` / `vk-mobile` | 后台内边距 16；前台容器 16；卡片双列；隐藏次要元素 |
| ≤380px | 组件内 media | 前台卡片变单列 |

前台网格：4 列 → 900px 3 列 → 640px 2 列 → 380px 1 列。
后台 `.vk-grid`：3 列 → 2 列 → 1 列。
移动端点击目标 ≥36px；顶栏高度前台 64→56，后台保持 60 左右。

## 4. 页面骨架

### 4.1 前台 `PortalLayout`

```
<header sticky 64px 毛玻璃> brand + 首页 / 管理员登录 </header>
<main> <RouterView/> </main>
<footer 22px 上下留白> vidkeep · 自有内容视频站 </footer>
```

- 背景：ink 渐变 + 顶部蓝色光晕（`radial-gradient(1100px 560px at 50% -18%, rgba(91,141,239,.16), transparent 62%)`）。
- 首页 `Home`：Hero（eyebrow + 渐变大标题 + 描述）→ 工具栏（分类 chip + 搜索）→ 结果统计 → 视频网格（`VideoCard`）→ 分页/空态/骨架。
- 详情/播放页复用同一外壳；播放页内容区沉浸、右栏剧集列表。

### 4.2 后台 `AdminLayout`

```
<el-container 100vh>
  <aside 220px ink-800> brand(60px) + el-menu(42px 项，圆角 8，active 蓝底 18%) </aside>
  <el-container>
     <header 60px 白底> 页面标题 / 横向菜单（窄屏） + 用户名 + 退出 </header>
     <main #f5f6f8> <RouterView/> </main>
  </el-container>
</el-container>
```

### 4.3 后台内容页骨架（统一使用全局工具类）

```html
<div class="vk-page">
  <h1 class="vk-page__title">页面标题</h1>
  <p class="vk-page__subtitle">说明文字</p>
  <section class="vk-grid"> … `.vk-card` 卡片 … </section>
</div>
```

- 列表页标准三段：**页头（标题 + 主操作）→ 筛选卡 → 表格卡 + 分页**（参考 `VideoList.vue`、`OperationLogs.vue`）。
- 表单页：左侧/上方基础信息卡 + 剧集表格卡 + 右上角保存/返回（`VideoEdit.vue`）。
- 上传页：作品选择卡 + `UploadPanel` + 结果跳转（`VideoUpload.vue`）。

### 4.4 登录页 / 站点口令

- 全屏深色径向渐变背景 + 极淡网格纹理 + 居中卡片（登录 max-width 400px / 口令 380px，圆角 16，padding 36/32）。
- 输入框高 40px，深色半透明底 + inset 描边，focus 时强调色描边 + 3px 光晕。
- 主按钮全宽、高 44px，蓝色渐变。

## 5. 组件规范

### 5.1 按钮

| 场景 | 规范 |
|---|---|
| 登录/口令/搜索提交 | 自定义渐变主按钮（36–44px 高，圆角 8–9） |
| 后台表单/页头主操作 | Element Plus `type="primary"`（已映射品牌蓝） |
| 行内操作（编辑/预览） | `el-button text type="primary" size="small"` |
| 危险操作（删除） | `el-button text type="danger" size="small"` + `ElMessageBox.confirm` 二次确认 |
| 次级/取消 | 默认按钮（白底描边） |

同一行最多 1 个主按钮；危险操作不与主操作并排紧邻。

### 5.2 表单

- label 字号 13、颜色 muted；`label-position="top"` 用于登录/口令。
- 输入框常规高 36（后台）/40（登录、口令）。
- 校验错误文案 12px、红色；错误展示在表单内联位置，不用全局弹窗。
- 回车提交（登录、口令、搜索）；提交中按钮 loading 且防重复提交。

### 5.3 表格与分页

- 表格卡：白底、1px 边框、12px 圆角；表头字号 13/600、表头底 `#fafbfc`、边框 `#f0f2f6`；行 hover 用 EP 默认。
- 长文本（路径、详情、标题）用 `show-overflow-tooltip`，不撑破列宽。
- 操作列固定在右侧，按钮为文字按钮；删除用 danger。
- 分页右对齐，页大小选项 10/20/50/100；空态文案「暂无数据 / 暂无操作日志」。

### 5.4 状态标签（`el-tag effect="plain"` 为主）

| 状态 | 类型 | 文案 |
|---|---|---|
| 转码 NONE | `info` | 未开始 |
| 转码 PENDING | `warning` | 排队中 |
| 转码 PROCESSING | `primary` | 转码中 |
| 转码 DONE | `success` | 已完成 |
| 转码 FAILED | `danger` | 失败 |

- 作品上下架：`el-switch`（1 上线 / 0 下线），操作中禁用防并发；标签 1=`success` 上线、0=`info` 下线。
- 审计日志模块：视频=`primary`、分类=`info`、上传=`success`、转码=`warning`；HTTP 方法：GET=`info`、POST=`success`、PUT/PATCH=`warning`、DELETE=`danger`。

### 5.5 视频卡片 `VideoCard`

- 封面 16:9（`aspect-ratio`），圆角 12，图片 `object-fit: cover`；
- 时长角标右下（11px、半透明黑底、圆角 5、等宽数字）；分类角标左上（胶囊、毛玻璃）；
- hover：卡片上浮 3px + 强调色描边 + 播放按钮淡入；无封面用 ink 渐变 + 播放占位；
- 标题最多 2 行、元信息（播放量/集数）12px muted。

### 5.6 上传区 `UploadPanel`

- 选择区：`#fafbfc` 底 + 1px 虚线边框 + 圆角 12，hover/拖拽时浅蓝底 + 强调色描边；内部图标 52px 圆形浅蓝底。
- 文件信息条：浅灰底 `#f7f9fc` + 1px 边框 + 圆角 10。
- 分片/转码进度用 `el-progress` + 状态 tag；失败展示后端 message 并提供重试/取消。

### 5.7 弹窗与确认

- 新建/编辑用 `el-dialog`（宽 480–560，圆角沿用 EP 主题）。
- 删除等破坏性操作必须 `ElMessageBox.confirm`，文案写清影响（如"将级联删除剧集与文件"）。

### 5.8 空态 / 加载 / 骨架

- 前台列表加载：骨架屏（16:9 封面块 + 两行标题条 + 扫光），不用居中 spinner。
- 后台列表加载：`v-loading` 覆盖表格；统计卡失败展示可重试 `el-alert`。
- 空态：居中图标（56px 圆形）+ 主文案 + 次要说明；文案中性、不卖萌。

### 5.9 反馈

- 成功用 `ElMessage.success`（如"已保存""秒传成功"）。
- 业务错误统一展示后端 `message`（`isBizError` 收窄后取 message），不展示堆栈。
- 播放地址过期（code 2005）用页面内状态块 + "重新获取播放地址"按钮，不用弹窗。
- 站点口令未通过（code 2004）由 `SiteGate` 全屏接管。

## 6. 可访问性与移动端

- 交互元素可键盘聚焦：`focus-visible` 必须有可见描边（示例：上传区 `outline 2px rgba(91,141,239,.5)`）。
- 品牌链接/导航加 `aria-label`；装饰性 SVG 加 `aria-hidden`。
- 深色面主文字 `#e8edf5` 对 `#080c13` 对比度充足；muted 只承载次要信息，不用于关键状态。
- 移动端：后台菜单折叠、表格横向滚动（EP 自带）、卡片双列、点击区 ≥36px。
- 动画必须尊重 `prefers-reduced-motion`。

## 7. 代码实现约定

1. **变量单一来源**：颜色/字体/断点只写在 `src/styles/_variables.scss`；页面 `<style scoped lang="scss">` 顶部 `@use '../../styles/variables' as *;`（`components/`、`layouts/` 为 `'../styles/variables'`）。
2. **全局工具类**：`.vk-page` / `.vk-page__title` / `.vk-page__subtitle` / `.vk-card` / `.vk-grid` / `.vk-muted` 定义在 `_base.scss`，新后台页面优先复用。
3. **Element Plus 主题**：只在 `_base.scss` 的 `:root` 覆盖 CSS 变量；组件内差异用 `:deep()` 限定在自身容器（如表格卡内覆盖表头色）。
4. **类名**：BEM 风格 `block__element--modifier`（如 `video-card__duration`、`home-chip--active`）；避免全局裸类名（`scoped` 内也保持前缀）。
5. **响应式**：统一用 `@include vk-tablet` / `@include vk-mobile`，不要散落写 media query（极窄 380px 除外）。
6. **图标**：当前未引入图标库，统一用内联 SVG（播放三角 mark）或文字符号；新增图标需先确认是否引入依赖。
7. **组件契约**：接口全部走 `src/api/*`，类型放 `src/types/*`，禁止 `any`；交互组件 props/emit 用 TS 类型声明。
8. **深色/浅色边界**：前台、登录、口令弹窗用深色令牌；后台内容区用浅色令牌；禁止在浅色卡片上直接使用深色文字变量（反之亦然）。
